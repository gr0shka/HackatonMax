🧪 Тестовый запрос (cURL)

Построение группового маршрута в Москве с бюджетом 90 минут:

curl -X POST http://localhost:8080/api/v1/routes/build \
  -H "Content-Type: application/json" \
  -d '{
    "user_ids": ["00000000-0000-0000-0000-000000000001"],
    "budget_minutes": 90,
    "start": {"lat": 55.751244, "lon": 37.618423},
    "finish": {"lat": 55.758900, "lon": 37.629500}
  }'
